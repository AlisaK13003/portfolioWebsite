# Alisa Katsionova Portfolio

![Portfolio homepage screenshot](assets/portfolio-screenshot.png)

Hey, this is my personal portfolio site: [alisakat.dev](https://alisakat.dev).

I built it to show the mix of work I like doing: product engineering, UI/UX, frontend development, game projects, and the little visual details that make a site feel personal. It has my featured projects, experience, a bit about me, and a contact section.

## What I Built

This is a custom portfolio with a cozy pixel-art direction. The homepage introduces me, then moves into an interactive project carousel where each project opens into a case-study style modal with screenshots, links, and notes about the work.

Some of the projects featured here include:

- MyLoops, a safety-focused mobile product
- Celo, a product/web experience
- Sealbound, a Godot game demo
- Sunny Days, a Unity game project
- Infolio, a contact manager web app

## How It Is Put Together

The current site is built with plain HTML, CSS, and JavaScript. The structure lives in `index.html`, the interactions live in `script.js`, and most of the custom pixel-art styling is in `styles.css`.

The design is intentionally handmade: custom navigation art, floating islands, animated butterflies, project modals, responsive layouts, and a warm pixel-art feel throughout.

## Running It Locally

Since this version is static, you can open `index.html` directly in a browser.

If you want a local server instead:

```bash
python -m http.server
```
